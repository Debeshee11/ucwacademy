Key terms, examples and exam traps

Holding period return

Holding period return is the total return over the period an investment is held, including income and price change, as a percentage of the initial value.

Example. An investment of ₹100 returns ₹115 including dividends.

Exam trap. This statement is false: Holding period return is the annual yield.

CAGR

CAGR is the constant annual rate at which an investment grows over a period longer than a year, assuming compounding.

Example. ₹1 lakh becomes ₹1.44 lakh in three years, about 13% a year.

Exam trap. This statement is false: CAGR is the simple average of yearly returns.

IRR

The internal rate of return is the rate that makes the present value of cash inflows equal to the outflows, used for irregular cash flows.

Example. A series of deposits and withdrawals is summarised in one annual rate.

Exam trap. This statement is false: IRR ignores the timing of cash flows.

XIRR

XIRR computes the annualised return for investments made on specific dates, such as monthly SIPs.

Example. An adviser wants the true return on a three-year SIP.

Exam trap. This statement is false: XIRR cannot be used for SIPs.

Real return

Real return is nominal return adjusted for inflation; it shows the growth in purchasing power.

Example. A 9% return with 6% inflation gives about 3% in real terms.

Exam trap. This statement is false: Real return equals nominal return.

Post-tax return

Post-tax return is the return after deducting tax, and is the figure that matters to the client.

Example. An investor compares products after tax.

Exam trap. This statement is false: Pre-tax return is the final return.

Time value of money

Money available now is worth more than the same amount in the future, because it can be invested to earn a return.

Example. ₹1 lakh today beats ₹1 lakh received in five years.

Exam trap. This statement is false: A rupee today and tomorrow are equal.

Present value

Present value is the current worth of a future sum, discounted at a given rate.

Example. ₹1.1 lakh receivable in a year at 10% is worth ₹1 lakh today.

Exam trap. This statement is false: Present value is always more than future value.

Future value

Future value is the amount an investment will grow to after earning a given return over a period.

Example. ₹1 lakh at 10% for two years grows to ₹1.21 lakh.

Exam trap. This statement is false: Future value is the value today of future cash flow.

Annuity versus perpetuity

An annuity pays a fixed amount for a fixed number of periods, while a perpetuity pays forever.

Example. A pension that continues for life with no end date is like a perpetuity.

Exam trap. This statement is false: A perpetuity stops after ten years.

Rule of 72

The Rule of 72 estimates the years for money to double by dividing 72 by the annual return in percent.

Example. At 8% an investment doubles in about nine years.

Exam trap. This statement is false: The Rule of 72 gives the tax payable.

Impact of costs

Fees and expense ratios reduce net returns, and the effect compounds over long periods.

Example. A 1% yearly cost on a 12% return reduces ending wealth materially over twenty years.

Exam trap. This statement is false: Costs have no effect on long-term returns.

Benchmarking

Comparing a portfolio's return with a relevant benchmark shows whether the manager added value after adjusting for risk.

Example. A fund's return is compared with its category index.

Exam trap. This statement is false: Any index can be used as a benchmark for any fund.

Time-weighted versus money-weighted

Time-weighted return removes the effect of cash flows, judging a manager; money-weighted return, like IRR, reflects the investor's own timing of flows.

Example. A manager's skill is judged ignoring the investor's deposits and withdrawals.

Exam trap. This statement is false: Both measures are always the same.
