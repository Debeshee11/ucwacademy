Key ideas you will take away

  • No guarantees in markets.
  • Urgency is a trick.
  • Never share OTP or PIN.
  • You never need a PIN to receive money.
  • Early payouts can be bait.
  • Fake apps block withdrawals.

Try a question

Q1. Which statement best describes “Guaranteed returns”?

  1. This is rushing you to decide now so you do not have time to check.
  2. This is someone giving investment advice without the registration the law requires.
  3. This is a promise of fixed high profit with no risk, which no genuine market investment can make.
  4. This describes an offer whose reward is far above what is normal for the risk.
Show the answer

C. Guaranteed returns: Guaranteed returns is a promise of fixed high profit with no risk, which no genuine market investment can make.

Q2. Which statement best describes “Phishing”?

  1. This is a fake message or link that tricks you into sharing passwords, card or bank details.
  2. This is a fake request to pay that is shown as money coming to you, which you must never approve with your PIN.
  3. This is a screen-sharing tool a fraudster asks you to install so they can see and control your phone.
  4. This is giving the one-time password to someone else, which lets them complete a transaction in your name.
Show the answer

A. Phishing: Phishing is a fake message or link that tricks you into sharing passwords, card or bank details.
