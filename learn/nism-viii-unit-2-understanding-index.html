Key terms, examples and exam traps

Stock index

A stock index is a number measuring the combined price performance of a basket of stocks, used as a market barometer and as the underlying of index derivatives.

Example. A single number tracks how 50 large companies are performing together.

Exam trap. This statement is false: An index measures the price of only one stock.

Free-float weighting

Free-float market capitalisation weighting weights each stock by the value of shares available for public trading, so promoter holdings are excluded.

Example. A company with a large promoter holding gets a smaller weight in the index.

Exam trap. This statement is false: Free-float weighting counts all issued shares.

Base value

An index starts at a base value on a base date; the Nifty 50 base is 1000 and the Sensex base is 100, and later values are relative to them.

Example. An index set at 1000 on its base date rises to 2000, doubling in value.

Exam trap. This statement is false: Every index starts at zero.

Index rebalancing

Index constituents are reviewed periodically and stocks replaced when they no longer meet criteria on market cap, liquidity and free float.

Example. An exchange replaces a stock that no longer qualifies for the index.

Exam trap. This statement is false: Index constituents never change.

Beta of a portfolio

Beta measures the sensitivity of a portfolio to market moves; a beta of 1.2 means it is expected to move 20% more than the index.

Example. A portfolio typically rises 12% when the index rises 10%.

Exam trap. This statement is false: Beta measures the dividend of a stock.
