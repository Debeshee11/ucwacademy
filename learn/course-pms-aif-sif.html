Q1. What is the minimum investment per client in a PMS under SEBI rules?

  1. ₹50 lakh
  2. ₹1 lakh
  3. ₹10 lakh
  4. ₹5 crore
Show the answer

A. SEBI set the minimum PMS investment at ₹50 lakh.

Q2. What is a 'hurdle rate' in a PMS performance fee?

  1. The minimum return the manager must beat before earning performance fees
  2. The client's minimum investment
  3. The brokerage rate
  4. The SEBI penalty rate
Show the answer

A. The manager earns the fee only on returns above the hurdle.
