Key terms, examples and exam traps

Time-weighted return

TWRR removes the effect of the timing and size of client cash flows, so it measures the manager's skill.

Example. A manager is measured regardless of client deposits.

Exam trap. This statement is false: TWRR depends on when the client adds money.

Money-weighted return

The money-weighted return is the internal rate of return and is affected by the timing of cash flows.

Example. A client's return is lower after a late deposit before a fall.

Exam trap. This statement is false: MWRR is independent of cash flow timing.

Sharpe ratio

The Sharpe ratio is excess return over the risk-free rate divided by standard deviation, showing return per unit of total risk.

Example. A fund returns 12% with 7% risk-free and 10% deviation, giving 0.5.

Exam trap. This statement is false: The Sharpe ratio uses beta as risk.

Treynor ratio

The Treynor ratio is excess return over the risk-free rate divided by beta, showing return per unit of systematic risk.

Example. A fund earns 5% excess with beta 1.25, giving 4%.

Exam trap. This statement is false: The Treynor ratio uses total risk.

Jensen's alpha

Jensen's alpha is the portfolio return less the CAPM expected return, and a positive value means outperformance for the beta taken.

Example. A fund earns 3% above its CAPM return.

Exam trap. This statement is false: A negative alpha shows outperformance.

Information ratio

The information ratio is active return divided by tracking error, showing return per unit of active risk.

Example. A manager earns 2% active return with 4% tracking error, giving 0.5.

Exam trap. This statement is false: The information ratio uses market risk.

Benchmark selection

A good benchmark is appropriate, investable, measurable and specified in advance, and reflects the manager's style.

Example. A large-cap manager uses a large-cap index.

Exam trap. This statement is false: Any index can serve as a benchmark.

Performance attribution

Attribution splits excess return into sources such as asset allocation, security selection and interaction.

Example. A report shows that stock selection added most of the outperformance.

Exam trap. This statement is false: Attribution shows only total return.

GIPS

GIPS are voluntary global standards for fair presentation and full disclosure of investment performance.

Example. A firm presents performance in line with GIPS.

Exam trap. This statement is false: GIPS are laws enforced by SEBI.

Valuation of securities

Securities in a portfolio are valued as per the norms in the regulations and the agreement, using market prices, and fair value where none exist.

Example. A listed share is valued at its closing price.

Exam trap. This statement is false: Each manager may value securities as it likes.

Standardised PMS performance

SEBI requires portfolio manager performance to be reported on a uniform basis, with returns computed using TWRR through a central platform.

Example. Managers' reported returns are comparable.

Exam trap. This statement is false: Each manager chooses its own method freely.

  1. Front running is trading ahead of a client's large order for the manager's own benefit and is a prohibited practice.

  3. The information ratio is active return divided by tracking error, showing return per unit of active risk.
  4. Strategic allocation sets long-term target weights across asset classes, based on objectives and risk, and is reviewed infrequently.
