Key terms, examples and exam traps

Time-weighted return

TWRR removes the effect of cash inflows and outflows, so it measures the manager's skill independent of the client's timing.

Example. A manager's return is computed between each deposit or withdrawal and then chained.

Exam trap. This statement is false: TWRR is affected by when the client adds money.

Money-weighted return

The money-weighted return (IRR) reflects the size and timing of cash flows and captures the client's actual experience.

Example. A client's own return depends on when she invested.

Exam trap. This statement is false: Money-weighted return ignores cash flow timing.

Annualised return

Annualised return converts a return over any period into an equivalent yearly rate for comparison.

Example. A 21% return over two years is about 10% a year.

Exam trap. This statement is false: Annualised return is the simple sum of all returns.

Benchmark

A benchmark is a standard index against which performance is compared, chosen to match the strategy.

Example. A large-cap portfolio is compared to a large-cap index.

Exam trap. This statement is false: Any index can serve as the benchmark.

Alpha

Alpha is the excess return of a portfolio over its benchmark or over what its risk would predict.

Example. A portfolio earns 3% more than the benchmark.

Exam trap. This statement is false: Alpha is the portfolio's total return.

Standard deviation

Standard deviation measures the volatility of returns; higher values indicate more risk.

Example. A portfolio's returns vary widely from month to month.

Exam trap. This statement is false: Standard deviation measures the average return.

Sharpe ratio

The Sharpe ratio measures excess return per unit of total risk; a higher ratio means better risk-adjusted performance.

Example. Two managers with equal returns are compared on risk taken.

Exam trap. This statement is false: The Sharpe ratio considers only returns.

Maximum drawdown

Maximum drawdown is the largest peak-to-trough decline in portfolio value, showing worst-case loss experienced.

Example. A portfolio fell 30% from its highest value.

Exam trap. This statement is false: Maximum drawdown measures the biggest gain.

Up and down capture

Capture ratios show how much of the benchmark's up and down moves a portfolio captures; high up-capture and low down-capture is desirable.

Example. A portfolio captures 110% of rising markets and 80% of falling markets.

Exam trap. This statement is false: A high down-capture ratio is desirable.

Consistency

Consistency, shown by rolling returns over many periods, matters more than a single period's return.

Example. A manager's three-year rolling returns beat the benchmark in most windows.

Exam trap. This statement is false: One strong year proves skill.

Standardised reporting

SEBI requires performance of portfolio managers to be reported in a uniform manner, using TWRR, through an independent central performance platform.

Example. Managers' returns can be compared on a common basis.

Exam trap. This statement is false: Each manager may choose its own method.

Gross versus net returns

Gross returns are before fees and expenses while net returns are after them; investors should compare net returns.

Example. An investor looks at returns after costs.

Exam trap. This statement is false: Gross returns are what the client receives.

Style drift

Style drift occurs when a manager moves away from the stated investment approach, which should be monitored.

Example. A large-cap approach quietly buys small caps.

Exam trap. This statement is false: Style drift is the sign of consistent discipline.

Risk-adjusted evaluation

Evaluating a manager involves return, risk, consistency, process and costs, not just headline returns.

Example. An adviser examines several measures before recommending a manager.

Exam trap. This statement is false: Only the last year's return matters.
