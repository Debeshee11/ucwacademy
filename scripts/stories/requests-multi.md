# Film wishes from the multi-asset course (lessons 61 to 75)

- duel: allow a signed value (a bar that goes left or right of zero) so a fall and a gain can sit in one row. Also keep the right-hand value label inside the frame when the right bar is the longest (it clips at 3 or more characters).
- lines: an optional second marker per series for "sold here" and "bought more here" events (lesson 72 describes them in captions only).
- stack: an optional legend row so short labels such as "Eq" and "Gold" do not need to be written inside narrow segments.
